# E-Commerce Sales Analysis using SQL

## Project Overview
This project analyzes sales data of an e-commerce platform using MySQL.
The goal is to extract business insights such as revenue trends, top products,
and customer spending behavior.

## Tech Stack
- MySQL
- MySQL Workbench
- SQL

## Database Design
The database consists of four tables:
- customers
- products
- orders
- order_items

## Key Analysis
- Total revenue generated
- Revenue by product category
- Top spending customers
- Average order value
- Repeat customers

## Key Learnings
- SQL JOINs and subqueries
- Foreign key constraints
- Business KPI calculations
- Real-world database design
